# running-calendar

2027년 봄 로드 마라톤의 접수 일정을 한 화면에서 보는 정적 웹앱. Vite와 바닐라 TypeScript로 만들었다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run check    # 날짜·상태 로직 점검
npm run build    # public/ics 생성 → dist/
```

## 데이터 규칙 (`data/races.json`)

- **공식 페이지에서 확인한 값만 넣는다.** GoRunning, 런조아, 러닝위키 같은 집계 사이트는 대회를 찾는 데만 쓴다.
- 공지되지 않은 값은 `null`로 두고, 화면에는 "미공지"로 표시된다. 추측해서 채우지 않는다.
- 날짜·시각 형식
  - `"2026-12-01T10:00"`: 시각까지 공지된 경우
  - `"2027-01-05"`: 날짜만 공지된 경우
- `status`
  - `auto`: `opens`/`closes` 값으로 상태를 계산한다.
  - `open` / `unknown` / `closed`: 공지 내용을 직접 적는다. 이때 `statusText`를 같이 쓴다.
- 대회를 수정하면 그 대회의 `verifiedAt`과 파일 맨 위 `updatedAt`도 고친다.

## 자동 처리 (데이터를 고치지 않아도 되는 것)

- `closes`가 지나거나 `status: "closed"`인 대회는 메인 목록에서 숨기고, 아래 "마감된 대회"로 옮긴다.
- 대회일이 지나면 목록에서 사라진다.
- "접수했어요"를 누른 대회는 "내 대회"로 올라가고, 대회 다음 날 24:00까지 보인다.
  - 이 체크는 브라우저의 localStorage에 저장된다. 그래서 다른 기기에서는 따로 체크해야 한다.

## 업데이트 주기

- **정기 점검:** 매주 월요일에 미공지 항목과 "정보 대기" 대회를 공식 페이지에서 다시 확인한다.
- **수시 점검:** 접수 오픈 하루 전에 시각이 바뀌지 않았는지 확인한다.
- **즉시 반영:** 마감 공지가 올라오면 `status: "closed"`로 바꾼다. 선착순 조기 마감은 날짜만 봐서는 알 수 없기 때문이다.
